# Judge demo — 90 seconds

**Live site:** https://airfare-index-sable.vercel.app

## Script

1. **Who benefits (20s)** — Home. Headline: daily airfare inflation for government — not a booking tip.  
   Point to **Who actually benefits**: MoSPI/NSO + policy watchers. Explicitly: not the everyday flyer.

2. **The number (20s)** — Today’s index + chart. “100 = start. Higher = air travel got costlier on this fixed basket.”  
   This chart is the product — not “book early.”

3. **Live (15s)** — Live tab: real SpiceJet receipts vs sample fallback. Honesty under bot walls.

4. **Proof (25s)** — Proof: government pain → what we add → click receipt trail.  
   “We augment MoSPI CPI. We do not replace it.”

5. **Prices only if asked (10s)** — Booking windows are sample-health diagnostics, not travel advice.

## One-liner

Official CPI airfare is slow; we give MoSPI a daily, same-rules, auditable air-inflation signal.
